# 🕷️ SUBWAY SPIDER

A bright, pleasant, colorful 2.5D endless runner game where **YOUR REAL BODY IS THE CONTROLLER**!

Built with **Phaser 3**, **TypeScript**, **Vite**, and **MediaPipe Tasks Vision** for zero-cost, 100% private, in-browser motion & hand gesture tracking.

---

## 🎮 How to Play

### 📷 Motion & Gesture Controls (Primary)
- **Lean Left**: Move to the Left Lane
- **Stand Center**: Stay in the Center Lane
- **Lean Right**: Move to the Right Lane
- **Physical Jump**: Jump up in front of your webcam to jump in-game!
- **Spider Web (🤟 or 🤘)**: Show the iconic Spider-Man sign (index + pinky extended, middle + ring curled) to shoot a web towards an overhead metal pipe, swing through the air, and land onto oncoming subway train roofs!

### ⌨️ Keyboard Fallback (Testing)
- **A / Left Arrow**: Shift Lane Left
- **D / Right Arrow**: Shift Lane Right
- **W / Up Arrow / Space**: Jump
- **E / F**: Shoot Web & Swing
- **Space / Enter / Click**: Restart on Game Over

---

## 🚇 Gameplay Highlights
- **Real Hand Gestures (🤟 / 🤘)**: Directly activates web shooting from character's extended hand to overhead metal pipes.
- **Dynamic Pendulum Swing Arc**: Pulls player upward and forward in a smooth, majestic swing.
- **Dynamic Subway Trains**: Short, Medium, and Long trains with clean metallic accents.
- **Train Roofs as Playable Platforms**: Land on train roofs via web swing or jump, run across them, and collect rooftop coins.
- **Automatic Train $\to$ Track Return**: When you reach the actual end of any train roof, you naturally leap off and return to running on the tracks.
- **Track Barriers**: Jump over or dodge yellow hazard hurdles.
- **Golden Coins**: Collect spinning arcade coins with particle explosions and score bonuses.
- **Web Audio API Synthesizer**: Retro arcade sound effects for webs, jumps, coins, and crashes.
